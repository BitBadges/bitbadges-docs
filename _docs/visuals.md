# Visuals

How the docs show things, and how each kind of visual stays correct without a person redrawing it.

## Principles

- A visual shows what the reader would **see**; a code block shows what they would **send**. Use a widget or screenshot for the first, JSON for the second, a diagram for the order of things.
- Every visual is generated from a source the tests can check: a mermaid fence, a widget directive with typed props, a screenshot manifest. No hand-drawn bitmaps, no pasted exports.
- Visuals follow the site theme. Diagrams and widgets read the CSS tokens; screenshots are captured on a fixed viewport with animations off.
- One visual per idea. If a paragraph says it, do not also draw it.

## Channels

| Channel | Source | Renders | Maintained by |
| --- | --- | --- | --- |
| Diagram | ```mermaid fence, optional `title=` | inline SVG at build time (`site/src/lib/docs/mermaid.ts`) | `site/tests/mermaid.test.ts` renders every fence in the corpus |
| Code fold | `fold=` on a fence, or automatic for long JSON | Collapsed / Full tabs on the figure | `site/tests/fold.test.ts` |
| Widget | `::widget{name=...}` directive with typed props | React mock rendered to static HTML (`site/src/components/widgets/`) | schema validation, HTML snapshots, a gallery page |
| Screenshot | one manifest entry per image (`site/scripts/capture-frontend-screenshots.ts`) | PNG under `.gitbook/assets/` | a check that fails on a missing or unreferenced image; re-capture on demand |

## Where each one belongs

- **Diagrams**: validation order, approval matching, the two paths from idea to on-chain, message lifecycles, IBC hops.
- **Widgets**: what an address, an approval, a permission row, a swap, or a collection card looks like on bitbadges.io. Best next to the JSON that produces it.
- **Screenshots**: the Using the Frontend walkthrough only. A screenshot of a component belongs to a widget instead, because a widget cannot go stale by pixel.
- **Folds**: any JSON over 40 lines, and any TypeScript interface where half the fields are optional plumbing.
